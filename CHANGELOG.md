# Changelog

## Unreleased — six-table design

- Prefer one thorough single-agent Run; manually switched stages use identical gates and checkpoints.
- Consolidate operational state into Companies, Applications, Sources, Runs, Settings and History. Retire generic orchestration tables.
- Verify PM function and configured experience/equivalent senior scope before inventory. Screen career goals before Queued, with recall-oriented pending checks instead of premature rejection.
- Replace routine per-read journal rows with meaningful change/business-event history and Run read scope.
- Make description capture admission-focused; clear unrelated roles are processed transiently, not stored in a shadow inventory.
- Preserve legacy outcomes and provenance during authorized verified migration; unreviewed broad queues require revalidation.

Earlier revisions introduced the larger workflow schema and full raw catalog storage. Those are migration aliases/evidence, not the active fresh-install design. MIT licensing, public onboarding, contributor/security guidance and dependency-free repository checks remain.

No installed runtime, account provisioning, production scan or certified harness integration is implied by these docs.
