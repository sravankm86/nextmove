# Shortlist a batch

Input: deduplicated inventory, complete job descriptions where available, scan coverage, private candidate criteria and master CV, and exact-role application history.

Record a disposition for each role evaluated or excluded. Apply explicit eligibility constraints first. Use actual responsibilities as well as title to assess seniority, ownership and domain fit. Read the full description before ranking plausible roles, including unconventional titles. Mark missing or ambiguous eligibility evidence as Unresolved and distinguish it from Ineligible. Compare eligible roles across the batch and cite the strongest role requirements, matching CV evidence and material gaps.

Return job keys, disposition (Shortlist, Pass, Ineligible, Unresolved or Duplicate), fit rationale and evidence. Include the number evaluated and any inventory or description gaps. Exclude applied, pending, rejected or user-declined exact roles from advancement. Reconsider unavailable roles only after verifying reopening. Record compensation only from the exact posting, with currency, geography and pay type.

Use a fresh task for shortlisting when supported. Evaluate this stage against a labeled sample of known eligible and ineligible roles before relying on unattended selection.
