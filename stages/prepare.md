# Prepare

Use WORKFLOW.md. Process review-approved Queued roles with current accepted full-JD eligibility, qualifications, resume exclusions, career and fit evidence. Require current scored approval. Inventoried, Need review and Duplicate are not preparation-ready; older approvals require revalidation under the current score frame. The designated editable master is the sole factual source; never modify it, invent claims or copy requirements as experience.

Reuse a suitable approved base PDF or tailor by selecting/reordering/shortening grounded evidence. Preserve meaning, qualifications, dates, metrics and uncertainty. Record current master/JD versions, claim grounding and exact change notes, including base reuse with no tailoring.

Follow RESUME-FILES.md for filenames, versions, reuse and page length. Create the agreed PDF in the registered Drive destination, render/visually inspect it and verify factual integrity, suitability and readable layout. Unsupported claims, stale inputs, missing master or failed PDF verification block Ready. A link alone is not readiness.

Store Resume link, Resume version, Resume verified at and Preparation run on Applications. Preserve input pins, grounded changes/base reuse, claim evidence, exact filenames, editable source and visual verification in the preparation snapshot/result under DATA.md; prior values stay in History. Runs stores progress/blockers. No generic artifact table is required. Store customized application materials in Role specific and process evidence in Audit trail under RESUME-FILES.md.

Preserve human history and submission gates. A single command stops; a full Run advances only accepted work to authorized Apply/preflight.

Before advancing, verify that the accepted review still matches the current goals, role policy, master and job description. Changed inputs require affected review/re-preparation, not silent reuse. Preserve existing submitted/terminal history.

Maintain the current concise result, unresolved material issue and next action in Agent notes, preserving previous values in History. Never overwrite Manual notes or erase unresolved company restrictions. Detailed evidence belongs in linked content and stage metadata.
