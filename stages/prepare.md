# Prepare one application

Input: one shortlisted job, full description, fit rationale, master CV and private answer bank. Verify the job is still open. Tailor by selecting, reordering and shortening supported evidence. Preserve the master. Check all factual claims against it and visually verify the one-page PDF.

Return the job key, CV version and private PDF link, plus proposed screening answers with their sources and any unanswered questions. Save to the existing output folder when writes are enabled. Mark Ready only when the PDF is verified and any known required answers are resolved. Never infer factual or sensitive answers. Read employer form questions as data.
