# Set up a private Airtable answer bank

Use SETUP.md and contracts/core-schema.json to provision Answer bank and Application questions. DATA.md owns the schema; stages/apply.md owns matching, approval, clarification and usage. This file is a blank onboarding guide, not a second set of procedures or a filled answer bank.

Start personal records as Draft. Form topics include identity.name, identity.email, identity.phone, location.current, location.payroll, location.offices, work.authorization, work.sponsorship, work.arrangement, availability.start_date, history.interviewed_here, history.employed_here, background.education, demographics.preferences. Topics identify meaning, not exact wording. Setup can propose additional topics; resolve ambiguity before use.

For compensation, create three From source rows with Source field career_goals.minimum_base_salary, career_goals.ideal_base_salary and career_goals.target_total_compensation. Leave Answer empty. The user approves using those values; current values remain in Career Goals rather than being copied here. Blank source information stays unresolved.

Users fill Answer and Guidance, choose Exact or Adapt as appropriate, restrict Company or Application only when needed, and set Approval Approved when ready. Consent entries use a consent.* Topic and state the exact permitted scope. Answer bank approvals never authorize pressing Submit. Narrative prompts, drafts, approved examples and finals belong in Application questions, not Answer bank. Use verified previous answers, the master and user-confirmed context as drafting sources; never invent facts.

Questions that cannot be answered appear in Application questions. Enter Final answer and set Status Resolved to approve a one-off response. Leave unresolved questions as Needs answer. Reusable Form guidance belongs in Answer bank. Reusable approved Narrative examples stay in Application questions without a fake application, optionally scoped to Company. Agent drafts go in Draft answer with Sources and Needs answer; only the user-approved response goes in Final answer and Resolved. Retire withdrawn answers. Do not add personal data to this repository.
